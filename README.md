# Old Games

Hans's early games, rebuilt in JavaScript and improved. Played in the browser, one folder per game.

Live: https://builtbysai.com/old-games/

## Games

- **Bigger Balls** (`bigger-balls/`) — eat smaller balls to get big, avoid bigger ones. JS rebuild of the 2019 LÖVE/Lua original. Drag to steer, FIRE to shoot.
- Word Beater — coming
- Square — coming
- Simon Says — coming

The originals stay archived in their own private repos (`builtbysai/bigger-balls`, `builtbysai/word-beater`, `builtbysai/square`, `builtbysai/simon-says`).
